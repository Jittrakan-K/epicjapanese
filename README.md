# Nihongo Line · 日本語ライン

เว็บเรียนภาษาญี่ปุ่นสำหรับคนไทย ตั้งแต่ฮิรางานะตัวแรกจนถึง JLPT N1 วางเส้นทางเป็นแผนที่รถไฟ 6 สาย 60 สถานี ผ่านแบบทดสอบท้ายบทได้ 80% ขึ้นไปจะได้ตราประทับ (ฮังโกะ) บนตั๋ว

เป็น HTML/CSS/JS ล้วน ไม่ต้อง build ความคืบหน้าเก็บใน `localStorage` ของเบราว์เซอร์ และซิงก์ขึ้น Firebase เมื่อมีบัญชี

## มีอะไรบ้าง

- **แผนที่การเรียน** สายคานะ → N5 → N4 → N3 → N2 → N1 แต่ละสายมีบทเรียน สถานีอ่าน และสอบท้ายสาย ป้าย 現在地 บอกว่าอยู่ตรงไหน
- **ตั๋ว 乗車券** สรุปความคืบหน้า และช่องตราประทับประจำสาย
- **บทเรียน** คำอธิบายภาษาไทย คำศัพท์ (ฟูริงานะ โรมาจิ เปิดปิดได้) ไวยากรณ์พร้อมตัวอย่างและคำแปล คันจิพร้อมคำอ่านอง/คุน
- **แบบทดสอบ** 10 ข้อต่อบท 20 ข้อต่อสอบท้ายสาย ใช้คีย์บอร์ด 1–4 และ Enter ได้
- **ทบทวนแบบเว้นระยะ (SRS)** คำศัพท์และคันจิของบทที่ผ่านจะเข้ากองทบทวนอัตโนมัติ
- **ตารางคานะ** พร้อมเสียง และทดสอบด่วน 20 ข้อ
- **ฝึกเขียน** บนกระดาษเก็นโคโยชิ เขียนทับตัวแบบด้วยนิ้วหรือเมาส์
- **คลังคันจิ คลังไวยากรณ์ ค้นหา** ค้นได้ทั้งคำไทย ญี่ปุ่น และโรมาจิ
- **สถิติ** ปฏิทินกิจกรรม 12 เดือน XP สตรีค ความแม่นยำ
- **สำรอง/นำเข้า** ความคืบหน้าเป็นไฟล์ JSON
- **บัญชีออนไลน์แบบไม่ใช้อีเมล** สมัครด้วยชื่อผู้ใช้กับรหัสผ่าน เข้าเรียนได้ทุกเครื่องและซิงก์ความคืบหน้าเอง PIN ล็อกบัญชีในเครื่อง เก็บข้อมูลที่ Firebase (Auth + Firestore) กฎความปลอดภัยใน `firestore.rules` ตั้งค่าใน `js/cloud.js`
- เสียงอ่านใช้ Web Speech API ของเบราว์เซอร์ (ต้องมีเสียงภาษาญี่ปุ่นในเครื่อง)

## เปิดดูในเครื่อง

ดับเบิลคลิก `index.html` ได้เลย หรือรันเซิร์ฟเวอร์เล็ก ๆ

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## เผยแพร่ด้วย GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/epicjapanese/`

## โครงสร้าง

```
index.html        โครงหน้า เมนู และชุดไอคอน
css/app.css       ดีไซน์ทั้งหมด
js/app.js         router, แผนที่, บทเรียน, แบบทดสอบ, SRS, ฝึกเขียน, สถิติ
data/kana.js      สายคานะ
data/n5.js … n1.js   เนื้อหาแต่ละระดับ
assets/mark.svg   ไอคอนเว็บ
```

## เพิ่มเนื้อหา

แต่ละบทในไฟล์ `data/*.js` มีรูปแบบนี้ เพิ่มบทใหม่ต่อท้ายใน `lessons` แล้วแผนที่ แบบทดสอบ คลัง และการค้นหาจะอัปเดตเอง

```js
{
  id: 'n5-09', title: 'ชื่อบท', jp: '見出し',
  intro: 'คำอธิบายภาษาไทย',
  grammar: [{ p: 'รูปประโยค', m: 'ความหมาย', ex: '例文。', r: 'れいぶん (เว้นวรรคระหว่างคำช่วย)', th: 'คำแปล', note: '' }],
  vocab:   [['言葉', 'ことば', 'คำ ภาษา']],
  kanji:   [['語', 'ゴ', 'かた(る)', 'ภาษา คำพูด', '日本語', 'にほんご', 'ภาษาญี่ปุ่น']]
}
```

`id` ต้องไม่ซ้ำ และเมื่อเปลี่ยน `id` ของบทเดิม ความคืบหน้าของบทนั้นในเบราว์เซอร์ผู้เรียนจะหายไป

## หมายเหตุเรื่องเนื้อหา

เนื้อหาเป็นชุดแกนหลักของแต่ละระดับ (ไวยากรณ์ 169 รูป คำศัพท์ 564 คำ คันจิ 264 ตัว · สาย N5 14 บท สาย N4 12 บท) ไม่ครอบคลุมทุกอย่างที่ข้อสอบ JLPT ใช้ JLPT ไม่ได้ประกาศรายการคำศัพท์และไวยากรณ์อย่างเป็นทางการ ขอบเขตในเว็บอ้างอิงจากรายการที่ใช้กันทั่วไป ควรใช้คู่กับหนังสือเรียนและข้อสอบเก่า
